  |:---|:---|:---:|
  | Мова | Python | [версія] |

## ⚙️ Налаштування

  **1. Клонуйте репозиторій**
  ```bash
  git clone https://github.com/vanyadzygman/s-rent.git
  cd s-rent
  ```
  **2. Запустіть сервіси**
  ```bash
  docker-compose up -d
  ```

## 🚀 Запуск додатку

  ```bash
  [команда запуску]
  ```

## 🧪 Запуск тестів

  **Усі тести**
  ```bash
  pytest
  ```

  **Конкретний тестовий файл**
  ```bash
  pytest tests/[шлях до файлу]
  ```
  
  > [!WARNING]
  > Інтеграційні тести потребують запущеної БД (`docker-compose up -d`).
